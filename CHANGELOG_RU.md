# Vinogradovs Digitizer — версия 2.3.0

## Интерфейс и полноэкранный режим

- Утверждённый герб Виноградова сохранён в ресурсах и крупно выведен в заголовке.
- Новая цветовая схема: темно-синий фирменный блок, светлая рабочая область,
  контрастные кнопки и более крупные элементы ввода и навигации.
- Начальное Qt-окно адаптировано к виртуальному экрану noVNC (1600×860),
  в Docker запускается в максимизированном состоянии.
- Браузерная шапка noVNC переработана; кнопка «Развернуть» включает
  полноэкранный режим самого удалённого рабочего окна.
- Кнопка «На весь экран» / F11 скрывает правую панель параметров,
  оставляя больше места под исходную диаграмму.
- Шаг по глубине и числовые параметры по-прежнему вводятся с клавиатуры.

## Повышение надёжности цвета

- LAB-классификатор: хроматические каналы учитываются сильнее освещённости.
- Для достаточно насыщенных участков включён контроль HSV-тона.
- Программа сопоставляет пиксели с *другими* известными кривыми,
  если их области пересекаются. Неоднозначные пиксели исключаются.
- Предпросмотр показывает принятые пиксели зеленовато-бирюзовыми,
  спорные — жёлтым; результат нуждается в проверке по оригиналу.
- Несколько пипеточных образцов той же кривой по-прежнему объединяются.
- Кнопка «Перепроверить все кривые» пересчитывает первую кривую после
  добавления других цветовых палитр.
- Параметры цветоразличения сохраняются в проект и в метаданные Excel.

## Проверка

15 алгоритмических тестов выполнены успешно. Qt GUI smoke test
включён в проект и исполняется в Docker/Windows CI, где есть PySide6.
Фактический запуск Docker в среде подготовки архива не выполнялся.

## 2.3.0
- Единый стартовый splash 3.5 секунды с гербом и приветствием; приветствие больше не дублируется в рабочем окне.
- Docker/noVNC открывает приложение без отдельной брендированной шапки, а Qt-приложение работает полноэкранно.
- В рабочем окне оставлен компактный логотип и подпись Vinogradov's Digitizer.
- Параметры распознавания защищены от случайного изменения колесом мыши.
- Все числовые параметры распознавания заблокированы по умолчанию и меняются только после нажатия ✎.
- Добавлены подсказки «?» с объяснением, что происходит при увеличении и уменьшении каждого параметра.
- Добавлен профиль рекомендуемых значений для близких цветов и кнопка восстановления значений по умолчанию.
