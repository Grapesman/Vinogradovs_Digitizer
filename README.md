# Vinogradov's Digitizer

**Vinogradov's Digitizer** — программа для оцифровки геофизических диаграмм, каротажных кривых и других графиков по изображениям.

Программа позволяет загрузить фотографию или скан диаграммы, откалибровать глубину и шкалы, выбрать необходимые кривые по цвету и получить готовую таблицу значений с выгрузкой в Excel.

Распознавание выполняется **локально на компьютере** с помощью алгоритмов компьютерного зрения **OpenCV**. Для распознавания кривых не используются облачные AI-сервисы.

---

## 1. Для кого предназначена программа

Программа рассчитана на пользователя без навыков программирования.

После установки Windows-версии пользователю не потребуется отдельно устанавливать:

- Python;
- OpenCV;
- Docker;
- PyCharm;
- дополнительные библиотеки.

Windows-релиз является **нативным настольным приложением**. Браузер, localhost, Docker и Python для запуска конечному пользователю не требуются.

Работа с Windows-версией выглядит так:

1. Скачать установщик с GitHub.
2. Установить программу.
3. На рабочем столе появится ярлык **Vinogradov's Digitizer** с фирменным гербом.
4. Дважды щёлкнуть по ярлыку.
5. Дождаться заставки загрузки.
6. После запуска откроется обычное настольное окно **Vinogradov's Digitizer**.
7. Загрузить исходное изображение.
8. Выполнить оцифровку.
9. Сохранить Excel-файл или проект в любую удобную папку на компьютере.

## 5. Основное окно программы

После загрузки открывается рабочая область.

Слева находится изображение.

Справа находятся вкладки:

- **Подготовка**;
- **Шкалы**;
- **Кривые**;
- **Результат**.

В верхней части рабочей области находятся кнопки:

- **Вписать**;
- **Фокус на графике**.

Для большинства неочевидных кнопок предусмотрены подсказки. Наведите курсор мыши на кнопку и подождите — появится пояснение.

---

## 6. Кнопка «Вписать»

Кнопка **Вписать** автоматически меняет масштаб отображения так, чтобы всё изображение целиком помещалось в рабочую область.

Исходный файл при этом не изменяется.

---

## 7. Кнопка «Фокус на графике»

Кнопка **Фокус на графике** временно скрывает правую панель настроек и увеличивает область изображения.

Это удобно при:

- выборе точек;
- работе пипеткой;
- коррекции перспективы;
- ручной правке;
- работе с крупным графиком.

Повторное нажатие возвращает панель настроек.

# Вкладка «Подготовка»

## 8. Открыть фото

Кнопка **Открыть фото** открывает окно выбора изображения.

Выберите нужный файл и нажмите **Открыть**.

---

## 9. Поворот на 90°

Кнопки:

```text
↺ 90°
↻ 90°
```

поворачивают изображение влево или вправо на 90 градусов.

---

## 10. Автовыравнивание

Кнопка **Автовыравнивание** пытается определить небольшой наклон изображения по линиям графика и исправить его.

Используйте эту функцию, если скан или фотография немного наклонены.

---

## 11. Коррекция перспективы — 4 точки

Кнопка **Коррекция перспективы • 4 точки** используется, если фотография сделана под углом.

После нажатия укажите четыре угла рабочей области диаграммы.

Программа преобразует выбранную область в ровный прямоугольник.

После геометрического преобразования рекомендуется заново выполнить калибровку.

---

## 12. Вернуть исходное фото

Кнопка **Вернуть исходное фото** возвращает первоначально загруженное изображение.

Все геометрические преобразования рабочего изображения отменяются.

---

## 13. Калибровка глубины

Для определения глубины используются две известные точки:

- H1;
- H2.

Пример:

```text
H1 = 1000 м
H2 = 1200 м
```

Порядок действий:

1. Введите значение H1.
2. Введите значение H2.
3. Нажмите **Указать H1**.
4. Щёлкните по соответствующей горизонтали изображения.
5. Нажмите **Указать H2**.
6. Щёлкните по второй известной горизонтали.

После этого программа рассчитывает соответствие:

```text
координата изображения → глубина
```

---

## 14. Границы дорожек

Кнопка **Найти** пытается автоматически определить вертикальные линии-разделители между дорожками диаграммы.

Это вспомогательные линии.

Они не изменяют исходные данные.

Кнопка **Скрыть** убирает отображение найденных границ.

# Вкладка «Шкалы»

## 15. Для чего нужна шкала

Шкала определяет, как горизонтальная координата кривой превращается в реальное значение.

Можно создать любое количество шкал.

Например:

- Время;
- Амплитуда;
- Сопротивление;
- Пористость;
- Температура.

Одну шкалу можно использовать сразу для нескольких кривых.

---

## 16. Создание новой шкалы

Нажмите:

```text
+ Новая шкала
```

Заполните:

- название;
- единицу измерения;
- минимальное значение;
- максимальное значение;
- тип шкалы.

Пример:

```text
Название: Время
Единица: мкс
Минимум: 250
Максимум: 650
Тип: Линейная
```

---

## 17. Линейная шкала

Используется, когда одинаковому расстоянию соответствует одинаковое изменение значения.

Пример:

```text
100
200
300
400
500
```

---

## 18. Логарифмическая шкала

Используется для логарифмических шкал.

Пример:

```text
1
10
100
1000
```

Тип шкалы защищён от случайного изменения колесом мыши.

Чтобы изменить тип:

1. нажмите **✎**;
2. выберите нужное значение;
3. нажмите **✓**.

---

## 19. Выделить область шкалы

Кнопка **Выделить область шкалы** позволяет мышкой выделить участок изображения, соответствующий шкале.

Программа использует его для преобразования координаты X в реальное значение.

---

## 20. Первая и вторая отметка шкалы

Можно вручную указать две известные позиции:

- **Левая/первая отметка**;
- **Правая/вторая отметка**.

По этим точкам программа рассчитывает масштаб.

---

## 21. Сохранить / обновить шкалу

После настройки нажмите:

```text
Сохранить / обновить шкалу
```

После этого шкалу можно назначать кривым.

---

# Вкладка «Кривые»

## 22. Создание кривой

Нажмите:

```text
+ Новая кривая
```

Укажите:

- имя столбца;
- единицу измерения;
- шкалу.

Например:

```text
Имя: T1
Единица: мкс
Шкала: Время
```

Имя кривой станет названием столбца в итоговой таблице и Excel.

---

## 23. Выделить область кривой

Нажмите:

```text
Выделить область кривой
```

и выделите прямоугольную область, внутри которой проходит нужная линия.

Чем точнее ограничена область, тем меньше вероятность захвата:

- соседней кривой;
- текста;
- сетки;
- посторонних элементов.

---

## 24. Пипетка + образец

Нажмите:

```text
Пипетка + образец
```

и щёлкните по нужной кривой.

Программа запомнит цвет.

Для сложных изображений рекомендуется выбрать **2–4 образца одной и той же кривой** в разных местах.

Это особенно полезно, если:

- освещение неравномерное;
- линия выцвела;
- цвет меняется по глубине;
- изображение имеет шум.

---

## 25. Предпросмотр маски

Перед окончательным распознаванием рекомендуется нажать:

```text
Предпросмотр маски
```

Программа покажет, какие пиксели считает принадлежащими выбранной кривой.

В текущем режиме:

- зелёная или бирюзовая область — принятые пиксели;
- жёлтая область — неоднозначные пиксели.

Если программа захватывает соседнюю линию:

1. сузьте область кривой;
2. добавьте более чистые образцы;
3. уменьшите допуск цвета;
4. увеличьте разделение близких цветов.

---

## 26. Распознать / обновить

Кнопка:

```text
Распознать / обновить
```

выполняет трассировку текущей кривой.

Результат отображается поверх изображения.

---

## 27. Перепроверить все кривые

После добавления нескольких кривых, особенно похожих по цвету, нажмите:

```text
Перепроверить все кривые
```

Программа повторно сравнит палитры всех созданных кривых и заново выполнит распознавание.

---

## 28. Точная настройка распознавания

Большинству пользователей изменять эти параметры не требуется.

По умолчанию используется рекомендуемый профиль.

Поля защищены от случайного изменения колесом мыши.

Обозначения:

- **✎** — разрешить изменение;
- **✓** — сохранить значение;
- **?** — получить подробное пояснение.

---

## 29. Разделение цветов LAB

Определяет, насколько выбранный цвет должен быть ближе к текущей кривой, чем к соседней.

Если кривые смешиваются — **увеличить**.

Если появляется слишком много пропусков — **уменьшить**.

---

## 30. Допуск оттенка

Определяет допустимое изменение цветового тона.

Увеличить, если одна линия имеет заметно разные оттенки.

Уменьшить, если рядом проходят очень похожие по цвету кривые.

---

## 31. Допуск цвета LAB

Определяет допустимое расстояние от выбранного образца цвета.

Увеличить, если часть нужной линии не распознаётся.

Уменьшить, если программа захватывает соседние линии или сетку.

---

## 32. Максимальный скачок

Ограничивает максимально допустимое горизонтальное перемещение кривой между соседними строками.

Уменьшить, если программа перескакивает на соседнюю линию.

Увеличить, если реальная кривая имеет резкие изменения.

---

## 33. Разрыв

Определяет, сколько строк программа может пройти без уверенно найденного пикселя, продолжая считать найденные участки одной кривой.

Увеличить, если линия часто прерывается.

Уменьшить, если программа ошибочно соединяет удалённые участки.

---

## 34. Сглаживание

Определяет степень сглаживания траектории.

Увеличить, если линия сильно шумит.

Уменьшить, если необходимо сохранить небольшие реальные изменения.

---

## 35. Подавление сетки

Используется для уменьшения влияния длинных горизонтальных и вертикальных линий сетки.

Если сетка остаётся в маске — параметр можно увеличить.

Если вместе с сеткой исчезают участки самой кривой — уменьшить.

---

## 36. По умолчанию

Кнопка:

```text
↺ По умолчанию
```

возвращает рекомендуемые значения распознавания.

Если вы не уверены в настройках, используйте именно этот режим.

---

## 37. Ручная коррекция

После автоматического распознавания результат можно исправить вручную.

### Править точки

Позволяет перемещать ошибочно найденные точки.

### Удалять точки

Позволяет удалять ошибочные участки.

### Завершить правку

Выключает режим ручной коррекции.

Общая информация о проекте и исходном изображении.

## 43. Рекомендации для точной оцифровки

Для лучшего результата желательно использовать:

- изображение высокого разрешения;
- скан вместо фотографии, если он доступен;
- минимальное JPEG-сжатие;
- ровное освещение;
- исправленную перспективу;
- узкую область для каждой кривой;
- несколько образцов цвета.

Если две линии имеют почти одинаковый цвет, максимально точно ограничьте область каждой кривой.

---

## 44. Если распознаётся неправильная линия

Попробуйте по порядку:

1. сузить область кривой;
2. добавить 2–4 чистых образца цвета;
3. открыть **Предпросмотр маски**;
4. увеличить **Разделение цветов LAB**;
5. уменьшить **Допуск цвета LAB**;
6. уменьшить **Макс. скачок**;
7. нажать **Перепроверить все кривые**.

---

## 45. Если часть линии пропущена

Попробуйте:

1. добавить ещё один образец цвета;
2. увеличить **Допуск цвета LAB**;
3. немного увеличить **Допуск оттенка**;
4. увеличить допустимый разрыв;
5. проверить качество исходного изображения.

---

## 46. Ограничения

Качество оцифровки зависит от качества исходного изображения.

Программа не может восстановить детали, которых физически нет в исходном файле.

Очень низкое разрешение, размытие или сильное JPEG-сжатие могут потребовать ручной коррекции результата.

---

Распознавание выполняется локально.

Для обработки диаграмм не требуется отправка изображений во внешние AI-сервисы.

docker compose up --build -d

docker compose down

Она используется для обмена файлами между macOS и контейнером.

В релизной Windows-версии пользователь не привязан к этой папке.
