# Vinogradov's Digitizer — чек-лист релиза Windows

Версия: 2.3.0

Этот файл используется перед первой тестовой сборкой на GitHub Actions и перед публикацией официального GitHub Release.

---

## 1. Финальные имена

Проверить, что используются именно эти значения:

- Приложение: Vinogradov's Digitizer
- EXE: VinogradovsDigitizer.exe
- Установщик: Vinogradovs_Digitizer_Setup_2.3.0.exe
- Portable ZIP: Vinogradovs_Digitizer_Portable_2.3.0.zip
- Версия приложения: 2.3.0
- Windows File Version: 2.3.0.0
- Windows App ID: Vinogradov.VinogradovsDigitizer

---

## 2. Обязательные файлы проекта

В корне проекта должны существовать:

- main.py
- requirements.txt
- requirements-build.txt
- pyproject.toml
- VinogradovsDigitizer.spec
- build_windows_exe.bat
- build_windows_installer.bat
- build_windows_release.bat
- .gitignore

Также должны существовать:

- windows/version_info.txt
- installer/VinogradovsDigitizer.iss
- .github/workflows/build-windows.yml

---

## 3. Ресурсы

В папке assets должны существовать:

- assets/app_icon.png
- assets/VinogradovsDigitizer.ico
- assets/vinogradovs_digitizer_logo.png

Проверить визуально:

- герб не обрезан;
- фон иконки выглядит нормально;
- ICO корректно отображается в Windows;
- логотип заставки не размыт.

---

## 4. Проверка интерфейса

Перед релизом проверить:

- приложение запускается;
- splash screen появляется;
- главное окно открывается развёрнутым;
- правая панель имеет фиксированную ширину 500 px;
- разделитель панели нельзя случайно растянуть;
- кнопка «Фокус на графике» скрывает панель;
- после возврата панели ширина остаётся 500 px;
- нет горизонтальной прокрутки в панели настроек;
- элементы интерфейса не перекрывают друг друга.

---

## 5. Проверка файловых диалогов Windows

На настоящем Windows-компьютере проверить:

- «Открыть фото» открывает обычный Проводник Windows;
- доступны Рабочий стол, Документы, Загрузки и другие диски;
- можно открыть файл из папки с кириллицей;
- можно открыть файл из пути с пробелами;
- «Экспорт .xlsx» позволяет выбрать любую папку;
- «Сохранить проект» позволяет выбрать любую папку;
- «Открыть проект» работает через обычный Проводник Windows.

В Windows не должны отображаться Docker-пути:

- /data
- /host/home
- /host/volumes

---

## 6. Проверка алгоритмов

Перед публикацией проверить базовый рабочий сценарий:

1. Открыть изображение.
2. При необходимости повернуть или выровнять его.
3. Задать H1.
4. Задать H2.
5. Создать шкалу.
6. Задать минимум и максимум.
7. Выбрать линейную или логарифмическую шкалу.
8. Создать кривую.
9. Назначить кривой шкалу.
10. Выделить ROI кривой.
11. Добавить образцы цвета.
12. Выполнить распознавание.
13. Проверить маску.
14. Построить таблицу.
15. Экспортировать XLSX.
16. Сохранить проект.
17. Закрыть приложение.
18. Снова открыть проект.

---

## 7. Автоматические тесты

Перед сборкой должны пройти:

- tests/test_processing.py
- tests/test_ui_smoke.py
- tests/test_windows_package.py

Команда:

python -m pytest tests -q

Если хотя бы один тест падает, релиз не публиковать.

## 8. PyInstaller

После сборки должен существовать:

dist\VinogradovsDigitizer\VinogradovsDigitizer.exe

Проверить:

- EXE запускается;
- рядом не появляется CMD;
- splash screen отображается;
- иконка приложения правильная;
- в свойствах файла указана версия 2.3.0.0;
- Product Name: Vinogradov's Digitizer;
- Original Filename: VinogradovsDigitizer.exe.

---

## 9. Inno Setup

После сборки установщика должен существовать:

release\Vinogradovs_Digitizer_Setup_2.3.0.exe

Проверить:

- установка проходит без Python;
- установка проходит без Docker;
- права администратора для обычной установки не требуются;
- приложение появляется в меню Пуск;
- ярлык на рабочем столе называется Vinogradov's Digitizer;
- ярлык использует герб;
- удаление приложения через Windows работает.

---

## 10. Чистый Windows-компьютер

Перед официальной публикацией желательно проверить установщик на компьютере, где нет:

- Python;
- Docker;
- PySide6;
- OpenCV;
- среды разработки проекта.

Это ключевая проверка того, что установщик действительно самодостаточный.

- в Диспетчере задач не остаётся VinogradovsDigitizer.exe;
- повторный запуск работает нормально.

## 17. SmartScreen

До добавления цифровой подписи Windows может показать предупреждение Microsoft Defender SmartScreen о неизвестном издателе.

Это ожидаемо для нового неподписанного приложения.

Позже можно добавить Windows Code Signing без изменения основной архитектуры программы.

## 18. Запрет публикации

Не публиковать официальный Release, если:

- падают автоматические тесты;
- EXE не запускается на чистой Windows;
- не работает открытие или сохранение файлов;
- не работает экспорт Excel;
- не работает сохранение/открытие проекта;
- ярлык имеет неправильную иконку;
- версия файлов не совпадает с 2.3.0;
- после закрытия приложения остаётся процесс;
- установщик требует Python или Docker.
