VINOGRADOV'S DIGITIZER 2.3.0 — УСТАНОВКА НА WINDOWS
====================================================

Vinogradov's Digitizer — нативное настольное приложение для Windows.

Для запуска конечному пользователю НЕ требуются:
- Python;
- Docker;
- OpenCV;
- PySide6;
- дополнительные библиотеки или среды разработки.


ВАРИАНТ 1. ГОТОВЫЙ УСТАНОВЩИК
==============================

Рекомендуемый вариант для обычного пользователя.

1. Скачайте файл:

   Vinogradovs_Digitizer_Setup_2.3.0.exe

2. Запустите установщик двойным щелчком.

3. Пройдите стандартные шаги установки.

   Установщик работает для текущего пользователя и не требует
   отдельной установки Python или Docker.

4. Оставьте включённым пункт создания ярлыка на рабочем столе,
   если хотите запускать программу с рабочего стола.

5. После установки появится ярлык:

   Vinogradov's Digitizer

   Ярлык использует фирменный герб приложения.

6. Запустите программу двойным щелчком по ярлыку.

7. При запуске появится заставка с гербом и надписью:

   Vinogradov's Digitizer

   Добро пожаловать в дигитайзер Виноградова

8. После заставки откроется обычное окно приложения Windows.

   Браузер и localhost для Windows-версии не используются.


РАБОТА С ФАЙЛАМИ
================

Открытие изображения
--------------------

Нажмите кнопку:

   Открыть фото

Откроется стандартный Проводник Windows.

Можно выбирать изображения из любых доступных папок и дисков:

- Рабочий стол;
- Документы;
- Загрузки;
- локальные диски;
- внешние накопители;
- сетевые папки, доступные пользователю.

Поддерживаемые форматы:

- PNG;
- JPG;
- JPEG;
- BMP.

Пути с русскими буквами и пробелами поддерживаются.


Сохранение Excel
----------------

На вкладке «Результат» нажмите:

   Экспорт .xlsx

После этого выберите нужную папку через стандартное окно
сохранения Windows.


Сохранение проекта
------------------

Проект можно сохранить в любую доступную папку.

При повторном открытии проекта программа загрузит сохранённое
рабочее изображение и параметры проекта.


ЗАВЕРШЕНИЕ РАБОТЫ
=================

Чтобы завершить работу, закройте главное окно приложения обычным
крестиком Windows.

После закрытия главного окна VinogradovsDigitizer.exe должен
полностью завершиться.


ВАРИАНТ 2. PORTABLE
===================

Если установка не нужна, можно использовать portable-версию:

   Vinogradovs_Digitizer_Portable_2.3.0.zip

1. Распакуйте ZIP в обычную папку.

2. Не удаляйте папку:

   _internal

3. Запустите:

   VinogradovsDigitizer.exe

Portable-версия также не требует установленного Python или Docker.


WINDOWS SMARTSCREEN
===================

На текущем этапе установщик может быть выпущен без коммерческой
цифровой подписи Code Signing.

Поэтому Microsoft Defender SmartScreen на некоторых компьютерах
может показать предупреждение о неизвестном издателе.

Это связано с отсутствием цифровой подписи и репутации у нового
EXE-файла, а не с необходимостью установки Python или Docker.
