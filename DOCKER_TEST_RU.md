# Vinogradovs Digitizer 2.2 — Docker Test

Эта сборка предназначена для проверки интерфейса и алгоритмов на macOS перед выпуском Windows EXE.

## Что изменилось в 2.2

- обновлённая крупная фирменная шапка с утверждённым гербом и названием;
- приложение запускается **максимизированным внутри виртуального экрана** Docker;
- noVNC использует более широкий экран 1600×860, адаптивный браузерный слой и кнопку «Развернуть»;
- в рабочей области есть кнопка «На весь экран» / F11 для временного скрытия настроек;
- современный интерьер интерфейса: новые вкладки, карточки, поля, контрастные кнопки;
- точное разделение близких цветов: LAB с усилением цветовых каналов + HSV по тону;
- при нескольких распознанных кривых конкурирующие палитры разделяются с настраиваемым отступом LAB;
- спорные пиксели в предпросмотре **жёлтые и исключены**, зелёные — приняты;
- кнопка «Перепроверить все кривые» разделяет краски повторно после добавления остальных кривых;
- модернизированный интерфейс в стиле desktop-приложения;
- H1/H2, минимум/максимум шкалы и шаг глубины вводятся напрямую с клавиатуры;
- отдельная вкладка **Шкалы**: можно создать неограниченное количество линейных и логарифмических шкал;
- шкала калибруется выделением прямоугольной области либо двумя отметками X1/X2;
- программа рассчитывает преобразование `пиксель → значение` и пытается автоматически оценить цену деления по вертикальной сетке;
- отдельная вкладка **Кривые**: неограниченное число кривых;
- каждой кривой назначается любая созданная шкала;
- для одной кривой можно взять несколько образцов цвета пипеткой — полезно при неравномерном освещении и выцветшей печати;
- экспорт Excel формирует H + все добавленные кривые, а также листы Curves, Scales и Project.

## Запуск на Mac

1. Запустите Docker Desktop.
2. Если оставили запущенной старую версию с прежним именем контейнера,
   один раз выполните `docker rm -f vinogradovs-digitizer` (или остановите её
   через `docker compose down` в **старой** папке).
3. Распакуйте архив в **новую** папку. Ранее загруженные фото при необходимости
   скопируйте в новую `data`. Положите тестовые PNG/JPG/JPEG/BMP в папку `data`.
4. В Terminal перейдите в папку проекта и выполните:

```bash
docker compose up --build -d
```

5. Откройте:

```text
http://localhost:6080/
```

Или дважды нажмите `docker_start_macos.command`.

## Остановка

```bash
docker compose down
```

## Рекомендуемый тест

1. **Подготовка** → открыть фото → исправить поворот/перспективу → задать H1/H2 и вписать значения.
2. **Шкалы** → `+ Новая шкала` → вписать Min/Max → `Выделить область шкалы` → сохранить.
3. **Кривые** → `+ Новая кривая` → назначить шкалу → выделить ROI → взять 2–3 образца цвета одной кривой → распознать.
4. Повторить пункт 3 для второй/третьей кривой. Вернуться к первой кривой,
   открыть «Предпросмотр маски» и проверить, что линии разделены:
   **зелёные пиксели — приняты**, **жёлтые — спорные и исключены**.
5. На вкладке «Кривые» нажать **«Перепроверить все кривые»**, чтобы разделение
   применилось также к первой кривой, распознанной ещё до появления второй.
6. **Результат** → вписать шаг H → построить таблицу → экспортировать Excel в `/data`.

## Важные ограничения

Похожий цвет не всегда означает, что кривые различимы: при одинаковой краске,
сильном выцветании, пересечениях и размытости алгоритм может не определить
принадлежность пикселя. Программа показывает неоднозначность, а не выдаёт
догадку за достоверный результат. Сузьте ROI, добавьте чистые образцы,
сравните наложенные кривые с оригиналом и при необходимости правьте вручную.

Если Safari оставляет чёрные поля: в верхней панели браузера нажмите
**«Развернуть»**. При другом соотношении сторон монитора можно изменить
разрешение виртуального экрана без изменения кода. Например:

```bash
VNC_RESOLUTION=1440x900 docker compose up -d --force-recreate
```

Затем обновите браузер. Для обычного Mac рекомендуемый вариант —
по умолчанию `1600x860`. В интерфейсе кнопка **«На весь экран»** / клавиша F11
временно скрывает правую панель для подробной работы с изображением.

Проверка контейнера после сборки:

```bash
docker compose run --rm --entrypoint /app/docker_smoke_test.sh vinogradovs-digitizer
```

Если приложение не открылось, посмотрите `docker compose logs --tail=100`.
