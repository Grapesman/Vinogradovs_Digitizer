# Алгоритм Vinogradovs Digitizer 2.0

## 1. Геометрическая подготовка

Телефонная фотография может иметь три независимые геометрические проблемы: поворот на 90°, небольшой остаточный наклон и перспективную трапецию. Они исправляются раздельно.

Для 4-точечной коррекции пользователь указывает четыре угла. Точки автоматически упорядочиваются как TL/TR/BR/BL, после чего OpenCV строит матрицу гомографии `getPerspectiveTransform` и выполняет `warpPerspective`.

После любой геометрической операции старая калибровка сбрасывается: координаты пикселей уже изменились.

## 2. Калибровка H

Две точки `(y1, H1)` и `(y2, H2)` задают линейное соответствие между вертикальной координатой пикселя и глубиной. Это устойчивее OCR и позволяет работать даже с рукописными/плохо сфотографированными шкалами.

## 3. Дорожка

Каждая кривая хранит собственный ROI `(x, y, width, height)`. Поэтому на одном листе можно оцифровать кривые с разными диапазонами и разными физическими единицами.

## 4. Цветовая сегментация

Выбранный цвет BGR преобразуется в LAB. Для каждого пикселя вычисляется евклидово расстояние до эталонного LAB. Пиксели с расстоянием меньше пользовательского допуска попадают в бинарную маску.

LAB используется потому, что он устойчивее прямого сравнения RGB при изменении яркости бумаги и освещения.

## 5. Подавление сетки

Сначала строится адаптивная бинаризация серого ROI. Затем длинные горизонтальные и вертикальные структуры выделяются морфологическим opening с вытянутыми ядрами. Полученная маска сетки вычитается из цветовой маски.

Ядра намеренно длинные, чтобы локально вертикальные фрагменты самой кривой не принимались за сетку.

## 6. Трассировка

В каждой строке маски соседние пиксели объединяются в группы, а каждая группа заменяется центром. Получается набор кандидатов X для каждого Y.

От стартовой точки алгоритм идёт вверх и вниз. Следующая точка выбирается рядом с прогнозом `x_prev + dx_prev`. Ограничение `max_jump_px` предотвращает прыжки на соседнюю линию. Разрывы до заданной длины могут быть перескочены поиском продолжения.

После трассировки применяется медианное и мягкое гауссово сглаживание. Короткие внутренние разрывы интерполируются, длинные сохраняются как отсутствие данных.

## 7. Качество

Для каждой кривой вычисляются:

- `coverage_pct` — доля строк ROI, где существует точка;
- `p95_jump_px` — 95-й процентиль горизонтального скачка между соседними точками;
- `max_gap_rows` — максимальный обнаруженный разрыв;
- `score` — эвристический индикатор 0–100.

`score` предназначен для сортировки/визуальной проверки и не является физической погрешностью измерения.

## 8. Таблица

После преобразования в `(H, value)` данные интерполируются на равномерную сетку H только внутри фактического диапазона покрытия каждой кривой. Вне покрытия остаётся `NaN`, который экспортируется как пустая ячейка Excel.
